# Code Change & Git Workflow Protocol

When requested to make any code changes, always adhere to this workflow:

1. **Inspect First**: Inspect and understand the existing codebase, structure, and relevant files before modifying anything.
2. **Implement Locally**: Apply the requested change cleanly in the local workspace.
3. **Test & Report**: Run relevant tests and report their results clearly.
4. **Review & Diff**: Show the modified files and provide a unified Git diff.
5. **Approval Required**: Wait for explicit user approval before committing or pushing any changes.
6. **Commit & Push**: After receiving approval, commit the changes with a clear, descriptive commit message and push to the correct GitHub branch.
7. **Safety Guardrails**: Never overwrite unrelated work, never expose secrets or credentials, and never push unreviewed or unapproved changes.
